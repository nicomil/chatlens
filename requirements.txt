# Dependencies of the text analysis pipeline.
#
#   pip install -r requirements.txt
#
# The deterministic text measures (text_metrics, aggregate) run on the standard
# library alone: nothing below is needed for that stage. These entries serve the
# optional stages.

# Validated, open-source sentiment. Without it text_metrics falls back to the
# seed dictionaries and says so in the sentiment_backend column.
vaderSentiment>=3.3.2

# Validation rubric (src/llm_rubric.py) and TopicGPT's client.
# The rubric's provider is interchangeable: only the library matching the key
# you use is required. `openai` is needed by TopicGPT anyway, and is also the
# client for local models served through Ollama.
#
# The upper bounds are not our choice: TopicGPT declares openai<2 and
# anthropic<1, and installing it downgrades these libraries regardless.
# Declaring them here makes the environment identical whatever the install
# order, instead of depending on whoever comes last.
openai>=1.54,<2
pydantic>=2.0
anthropic>=0.40,<1   # only if you pick Claude as the rubric's judge

# TopicGPT (Pham et al., 2024) is not installed from here: the prompt files are
# part of the method and live in the repository, not in the published package.
#   git clone https://github.com/chtmp223/topicGPT.git
#   pip install ./topicGPT
# Install from the repository rather than PyPI: release 0.2.7 imports vLLM at
# top level and cannot be installed on macOS without a GPU, while the main
# branch has already made it an optional extra.
